# dosely-site

Dosely（iOSアプリ）の公開ページ（プライバシーポリシー・利用規約・特定商取引法に基づく表記・
お問い合わせ）です。GitHub Pagesで `https://<user>.github.io/dosely/` として公開しています。

このリポジトリはDoseslyアプリ本体のソースコードとは別管理です（アプリ側の非公開な社内ドキュメントを
誤って公開しないため）。

## 公開前に確認すること

- `tokushoho.html`・`support.html` 内の `プレースホルダー` 表示箇所（事業者名・所在地・
  電話番号・メールアドレス・管轄裁判所）を実際の情報に差し替える
- `terms.html` の管轄裁判所を記入する
- 内容を法務・薬事の専門家に確認してもらう（本サイトの文面は監修前ドラフトです）

## ローカルでの確認方法

静的HTMLのみなので、`index.html` をブラウザで直接開くか、以下のように簡易サーバーを立てて確認できます。

```bash
python3 -m http.server 8000
```
